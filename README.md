# Station Météo Partie Web

Ceci est la partie WEB de notre projet de Station Météo elle contient le création de compte, l'appairage et les graphiques de temperature et d'humidité.

Pour lance la partie WEB vous devez :

## 1 installer les modules suivant : 

### Paho :

```
pip install paho-mqtt
```

### JWT :

```
pip install PyJWT
```

### Warning !!!

Penser à update pip

```
python.exe -m pip install --upgrade pip
```

# 2 lancer le code :

Lancer broker.py:

```
python broker.py   
```

Puis lancer server.py :

```
python server.py   
```


### Warning !!!!!

Ne pas ouvir le code sur Edge.

Les graphiques ne s'affichent pas sur Edge.
